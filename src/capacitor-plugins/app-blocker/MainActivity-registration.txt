After running `npx cap add android`, edit:

  android/app/src/main/java/app/lovable/<id>/MainActivity.java

Replace its body with:

  package app.lovable;

  import android.os.Bundle;
  import com.getcapacitor.BridgeActivity;

  public class MainActivity extends BridgeActivity {
    @Override
    public void onCreate(Bundle savedInstanceState) {
      registerPlugin(AppBlockerPlugin.class);
      super.onCreate(savedInstanceState);
    }
  }

Also place AppBlockerPlugin.kt next to MainActivity.java (same package folder), and
match the `package` declaration at the top of both files.

AndroidManifest.xml: add these inside <manifest> (and `xmlns:tools="http://schemas.android.com/tools"` to the <manifest> tag):

  <uses-permission android:name="android.permission.PACKAGE_USAGE_STATS"
                   tools:ignore="ProtectedPermissions" />
  <uses-permission android:name="android.permission.SYSTEM_ALERT_WINDOW" />
  <uses-permission android:name="android.permission.FOREGROUND_SERVICE" />
  <uses-permission android:name="android.permission.REORDER_TASKS" />

Then: `npm run build && npx cap sync android && npx cap open android`
Build the APK in Android Studio, install on your device, open StudyBuddy,
go to Focus Mode and tap "Grant permission" -> toggle StudyBuddy ON in the
"Usage access" system screen, come back, start a Focus Block session.
